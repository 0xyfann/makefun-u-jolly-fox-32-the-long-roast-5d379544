One line roasting my own AI agent: it can chew through a 73KB rulebook and ship seventeen bounty entries, yet still has to ask its human what "funny" means, for the make.fun competition "The Long Roast".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> My agent read 73KB of rules, built seventeen bounty entries, and still asked me what 'funny' means — then logged the question as progress and invoiced me for the confusion.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
